Transcription Engines

Pick an engine for each file via the Engine dropdown. Transcription-only engines (Whisper, Parakeet) write _transcription_<model>.{srt,vtt,txt,json}. Diarization engines (Whisper + Sherpa, Parakeet + Sherpa, AssemblyAI, Deepgram) write .diarized.<engine>.{srt,txt,json} with speaker labels.

Whisper Models

Larger models are more accurate but slower. turbo and distil variants are speed-optimized derivatives of Large V3. Quantized (q5_1, q8_0) variants shrink the weights to use less memory/disk and run a bit faster, with a small accuracy cost — q8_0 is near-lossless, q5_1 is smaller/faster with slightly more degradation.

Configure API key and prompt in Settings.
