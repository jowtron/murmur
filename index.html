About Engines & Models

Transcription Engines

Pick an engine for each file via the Engine dropdown. All four produce the same .diarized.{srt,txt,json} outputs (except plain Whisper, which writes _transcription_<model>.{srt,vtt,txt,json} without speaker labels).

EngineCostNetworkDiarizationNotes
Whisper Free Offline — Local Whisper transcription only. Pair with the LLM chapter-detection pipeline.
Whisper + Sherpa Free Offline Yes Whisper for text + Sherpa-onnx (pyannote + NeMo SpeakerNet) for speakers. Pick any Whisper model in the Model dropdown. ~28 MB model download on first use.
AssemblyAI $0.17–$0.23/hr Cloud Yes Universal-2 ($0.17/hr) or Universal-3 Pro ($0.23/hr) + diarization add-on. Auto-fallback default. Configurable in Settings.
Deepgram ~$0.26/hr Cloud Yes Nova-3 model ($0.0043/min, diarization included). Faster than AssemblyAI on long files (single sync POST instead of upload+poll).

Whisper Models

Larger models are more accurate but slower. turbo and distil variants are speed-optimized derivatives of Large V3.

Chapters

Detect Chapters

Select one or more SRT/VTT/TXT transcript files to detect chapter boundaries via LLM. With "Snap to speech onset" enabled, chapter times are snapped to the nearest music-to-speech transition using YAMNet audio classification. Results auto-save next to source files. Configure API key and prompt in Settings.
